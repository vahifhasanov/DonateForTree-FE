# DonateForTree — лабораторна №6

React + Vite, React Router, власні React-хуки, fetch, Leaflet 1.9.4 та OpenStreetMap.
Дизайн попередніх лабораторних збережено. Інтерфейс англійською, сторінка 404 українською.

## Запуск

Потрібен Node.js 22.12+ (перевірено на 24.14).

```sh
npm ci
npm run dev:all
```

Відкрити http://127.0.0.1:5174. API: http://127.0.0.1:3001.
Якщо процес уже запущений, повторний запуск не потрібен.
Альтернатива — два термінали:

```sh
npm run api
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

За потреби скопіювати `.env.example` у `.env.local`, змінити `VITE_API_URL` і перезапустити Vite.
Порт API задає `API_PORT`, шлях бази — `DEMO_DB_PATH` (змінні середовища).
Mock API використовує вбудовані модулі Node.js, без серверного фреймворку та нових залежностей.

## Дані та навчальна авторизація

При першому запуску `mock/seed.json` копіюється у `mock/db.local.json`.
Нова база порожня: 0 посадок. Demo-акаунт також починає з 0 дерев. Старі seed-записи видаляє точна міграція з резервною копією, зберігаючи POST-записи.
Одна картка/маркер відповідає групі дерев. Статистика підсумовує `quantity`, а не кількість записів.
Ціна: 150 UAH за дерево, від 1 до 100 дерев; власна сума має бути кратною 150.
Файл бази зберігає нові посадки й облікові записи після перезапуску; він виключений із Git.
Seed не перезаписує наявну базу. Запускайте лише один процес API для одного файлу бази.

Демонстраційний вхід: `demo@example.com` / `DemoTree2026!`.
Реєстрація — лише з вигаданими даними та унікальним навчальним паролем.
Паролі хешуються на mock API через scrypt із випадковою сіллю; хеші не повертаються клієнту.
Браузер зберігає лише токен сесії у localStorage. Сесія перевіряється GET /auth/me,
діє до 24 годин і припиняється після перезапуску API. Потрібно увійти повторно; дані залишаються.
Це локальна навчальна модель: немає TLS, rate limiting, відновлення пароля, підтвердження пошти,
production-керування сесіями. Не публікуйте цей API в інтернеті та не вводьте справжні секрети.
Оплата відсутня; підтвердження створює лише демонстраційний запис.

## API та архітектура

- GET `/trees` — публічні посадки; GET `/trees/:id` — окрема посадка.
- GET `/my-trees` — посадки поточного користувача з Bearer-токеном.
- POST `/trees` — `{quantity: 5, species: "Maple", region: "lviv"}`; заголовки Authorization і Idempotency-Key.
- POST `/auth/register` — `{name, email, password}`; POST `/auth/login` — `{email, password}`.
- GET `/auth/me`, POST `/auth/logout` — перевірка та завершення сесії.

API сам визначає власника, дату, координати й суму. Повторний Idempotency-Key не створює дубліката.
`src/api` містить fetch, timeout, перевірку JSON та помилки; `src/hooks` — useAuth, useTrees,
useMyTrees, usePlantTree, useTreeFilters, useMutation. Запити читання скасовуються при демонтуванні.
`/trees` і `/plant` захищені; після входу користувач повертається до запитаного маршруту.

## Карта

Справжня Leaflet-карта: переміщення, масштабування, маркери груп, popup, фільтри області/породи/року,
пошук та скидання. Картка відкриває `/map?tree=ID` і відповідний popup.
Координати визначені наперед у відповідних областях України; вони не підтверджують фактичну посадку.
Leaflet JS/CSS завантажуються з unpkg з фіксованою версією та SRI за офіційним прикладом:
https://leafletjs.com/examples/quick-start/ . Підкладка: tile.openstreetmap.org з атрибуцією.
Потрібен інтернет до обох доменів. При збої доступне повідомлення та повторне завантаження.

## Перевірки

```sh
npm run lint
npm run test:unit
npm run build
npm run format:check
npm run test:e2e -- --browser chrome
```

Для Cypress мають працювати Vite на 5174 та API на 3001. E2E реєструє вигадані акаунти
і додає тестові посадки у поточну локальну базу. Для ізоляції задайте DEMO_DB_PATH перед запуском API.
Тест карти використовує справжню Leaflet; потребує доступу до CDN. Інші HTTP-помилки мокуються Cypress.
Vitest тестує правила, fetch і справжній тимчасовий HTTP API, включно з перезапуском та збереженням;
тимчасова тестова база не змінює основну базу.

У середовищі виконання: Vitest 46/46 і production build пройшли; фінальні результати наведені
в `docs/lab6-report.md`. Cypress не стартував через помилки Windows/GPU та доступу до профілю.
Браузерний доступ Chrome також не наданий. Візуальну перевірку карти, drag/zoom і адаптивності
потрібно завершити в користувацькому браузері; успішний E2E-прогін не заявляється.
