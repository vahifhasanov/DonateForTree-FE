# DonateForTree — лабораторна №7: бекенд

Продовження лабораторної №6: React 19, Vite, React Router, fetch, React Context,
власні хуки, Leaflet/OpenStreetMap. Власний бекенд: Node.js, Express 5,
`express.json()` та bcryptjs. Дизайн, маршрути сторінок і карта збережені.

## Запуск

Потрібні Node.js 22.12+ та npm; перевірено на Windows із Node.js 24.14.0.

```sh
npm ci
npm run dev:all
```

Фронтенд: http://127.0.0.1:5174. Express API: http://127.0.0.1:3001.
Альтернатива — окремі термінали:

```sh
npm run api
npm run dev
```

`npm run dev` використовує стандартний порт Vite (зазвичай 5173).
Для Cypress: `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`.
`VITE_API_URL` у `.env.local` перевизначає адресу API; приклад — `.env.example`.
`API_PORT` змінює порт бекенда; тоді потрібно також змінити `VITE_API_URL`.
Node не читає `.env.local`: серверні змінні задаються в терміналі.

## API

Відповіді — JSON; помилка має вигляд `{ "message": "..." }`.

| Метод | Маршрут          | Призначення                                      | Авторизація |
| ----- | ---------------- | ------------------------------------------------ | ----------- |
| POST  | `/auth/register` | `{name, email, password}` → `{user, token}`, 201 | Ні          |
| POST  | `/auth/login`    | `{email, password}` → `{user, token}`, 200       | Ні          |
| GET   | `/auth/me`       | `{id, name, email}` поточного користувача        | Bearer      |
| POST  | `/auth/logout`   | Відкликання токена, `{success: true}`            | Bearer      |
| GET   | `/trees`         | Масив усіх посадок для карти                     | Ні          |
| GET   | `/trees/:id`     | Одна посадка або 404                             | Ні          |
| GET   | `/my-trees`      | Масив посадок поточного користувача              | Bearer      |
| POST  | `/trees`         | Створення посадки, 201; повтор запиту — 200      | Bearer      |

Приклад тіла POST `/trees`:

```json
{ "quantity": 5, "species": "Maple", "region": "lviv" }
```

Заголовки: `Content-Type: application/json`, `Authorization: Bearer <token>` та
`Idempotency-Key: <унікальний ключ 8–100 символів>`.
Сервер перевіряє ціле `quantity` від 1 до 100, породу (Oak/Maple/Pine/Other)
і область (zakarpattia/lviv/kyiv/ivano-frankivsk), обчислює суму `quantity × 150 грн`,
визначає власника за токеном, дату та координати. Поля `total` і `userId` клієнта
не впливають на результат. Ключ зберігається з посадкою окремо для кожного власника.
Повтор із тими самими параметрами повертає наявний запис; зміна параметрів — 409.
Ключі не повертаються в HTTP-відповідях. Новий користувач отримує порожню колекцію.
Оплати та фізичної посадки немає.

## Авторизація та дані

`server/index.js` містить Express-маршрути, middleware авторизації, перевірки та
JSON-сховище. `mock/server.js` — лише сумісний експорт для попередніх тестів міграції.
`src/api`, контекст авторизації та хуки продовжують працювати з попереднім контрактом.

Email нормалізується і перевіряється на унікальність. Нові паролі хешуються bcryptjs
із cost 10. Довжина — 8–128 символів, але не більше 72 UTF-8 байтів через обмеження bcrypt.
Старі scrypt-хеші перевіряються старим алгоритмом та оновлюються до bcrypt після
успішного входу; паролі понад 72 байти залишаються scrypt, щоб уникнути обрізання.
Якщо локальний старий запис містить `password`, він хешується при старті, а поле видаляється.
Паролі, хеші й сіль не повертаються клієнту.

Токени — 32 криптографічно випадкові байти (`randomBytes`), строк дії — 24 години.
Сесії зберігаються в пам'яті; після logout або перезапуску сервера потрібен новий вхід.
Браузер зберігає токен у localStorage. Middleware перевіряє Bearer-токен для приватних
маршрутів; без нього відповідь 401. CORS дозволяє локальні HTTP-адреси localhost/127.0.0.1.
JSON обмежений 16 КіБ. Некоректні запити — 400, конфлікти — 409, невідомі адреси — 404,
помилки збереження — 500, завеликий JSON — 413, сторонній Origin — 403.

Робочий файл — `mock/db.local.json`, виключений із Git разом із тимчасовими файлами
та резервними копіями. Якщо його немає, використовується порожній `mock/seed.json`
та додається навчальний акаунт `demo@example.com` / `DemoTree2026!`.
Наявна база не перезаписується seed-даними. Збережена точна міграція старих демонстраційних
посадок із резервною копією; користувацькі записи зберігаються.
Запис виконується у тимчасовий файл із наступним перейменуванням; при помилці
реєстрації/посадки зміна в пам'яті скасовується. Запускайте один API на один файл бази.
Шлях перевизначає `API_DB_PATH` або сумісна змінна `DEMO_DB_PATH`.
Не додавайте робочі бази, токени й справжні персональні дані в Git.

## Тести

```sh
npm run lint
npm run build
npm run format:check
npm run test:unit
npm run test:e2e
git diff --check
```

Vitest перевіряє Express через справжні HTTP-запити `fetch`: реєстрацію, вхід,
помилки, розділення власників, ідемпотентність, перезапуск, міграцію та збій запису.
Supertest не потрібен. Усі серверні тести використовують окремі тимчасові бази в `.tmp`.

Перед Cypress запустіть `dev:all` із відокремленою базою, щоб не змінювати робочу:

```powershell
$env:API_DB_PATH = '.tmp/lab7-e2e/db.json'
npm run dev:all
```

В іншому терміналі — `npm run test:e2e`. Не запускайте другий API на тих самих портах.
Cypress використовує 5174/3001 і створює вигадані акаунти та посадки у тестовій базі.
Leaflet завантажується з unpkg, тайли — з OpenStreetMap; перевірці карти потрібен інтернет.

Це локальна навчальна система з одним JSON-файлом, без реальної оплати, TLS,
відновлення пароля та обмеження частоти запитів. Для публічного production-сервера
потрібні окремі заходи захисту та інше сховище. Докладні результати лабораторної:
[docs/lab7-report.md](docs/lab7-report.md). Матеріали попередніх лабораторних залишені в `docs/`.
