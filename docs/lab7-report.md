## Устройство сервера

Вся серверная логика размещена в одном понятном модуле server/index.js.
`createApi(databasePath)` создаёт Express-приложение и возвращает HTTP-сервер:
тесты могут использовать свободный порт и собственный временный файл.
При запуске `npm run api` модуль слушает только 127.0.0.1:3001.

Порядок middleware: локальный CORS и no-store → express.json с лимитом 16 КиБ →
маршруты с проверкой авторизации и JSON-объекта → 404 → общий обработчик ошибок.
CORS поддерживает Authorization и Idempotency-Key; сторонние Origin отклоняются.
Бизнес-валидация использует общие с фронтендом правила из src/utils/trees.js.
Новых баз данных, TypeScript, Docker, JWT-секретов и внешних mock API нет.

## Маршруты

| Метод | Адрес          | Успешный ответ                  | Доступ                  |
| ----- | -------------- | ------------------------------- | ----------------------- |
| POST  | /auth/register | 201, {user, token}              | Публичный               |
| POST  | /auth/login    | 200, {user, token}              | Публичный               |
| GET   | /auth/me       | 200, {id, name, email}          | Токен                   |
| POST  | /auth/logout   | 200, {success: true}            | Токен                   |
| GET   | /trees         | 200, массив всех посадок        | Публичный               |
| GET   | /trees/:id     | 200, одна посадка               | Публичный               |
| GET   | /my-trees      | 200, массив своих посадок       | Токен                   |
| POST  | /trees         | 201, новая посадка; 200, повтор | Токен + Idempotency-Key |

Форматы запросов сохранены из src/api: регистрация {name, email, password},
вход {email, password}, посадка {quantity, species, region}.
Ошибки возвращают {message}: 400 — параметры, 401 — авторизация, 404 — отсутствие,
409 — занятый email или конфликт ключа, 500 — внутренняя ошибка сохранения.
Дополнительно: 413 для слишком большого тела, 403 для запрещённого Origin.

## Авторизация

Email обрезается по краям и приводится к нижнему регистру; дубликат отклоняется.
Новый пароль хешируется bcryptjs, cost 10; сравнение выполняется через compareSync.
Проверяются имя, email, длина пароля и предел bcrypt в 72 UTF-8 байта.
Пароль, хеш и соль отсутствуют в публичном объекте пользователя.

Сессия содержит криптографически случайный 256-битный токен, userId и срок 24 часа.
Она хранится в памяти сервера, браузер сохраняет токен в localStorage.
`requireAuth` проверяет формат Bearer, наличие сессии, срок и пользователя.
Logout удаляет сессию, перезапуск сервера сбрасывает все сессии, но сохраняет данные.
Для /trees и /my-trees владелец берётся только из req.user, подмена userId в теле не работает.

## Хранение и бизнес-логика

По умолчанию используется прежний mock/db.local.json, исключённый из Git вместе
с временными файлами и резервными копиями. API_DB_PATH переопределяет путь;
старый DEMO_DB_PATH тоже поддерживается. Новая база содержит demo-аккаунт без посадок.
Хранилище сохраняется при регистрации и создании посадки через временный файл и rename.
При ошибке записи изменения пользователя/посадки в памяти откатываются.

Имеющиеся scrypt-хеши проверяются старым способом и обновляются до bcrypt после
правильного входа. Старое поле password хешируется при старте и удаляется.
Пароли длиннее 72 байт сохраняют scrypt, чтобы избежать потери части пароля.
Точная миграция старых seed-посадок с резервной копией сохранена из лабораторной №6.
Пользовательские записи и их идентификаторы сохраняются.

Количество — целое 1–100, цена — 150 грн/дерево, порода и область проверяются по спискам.
Сумму, дату, владельца и координаты определяет сервер. Общая карта получает все посадки,
личная коллекция фильтруется сервером по текущему пользователю.
Idempotency-Key сохраняется вместе с записью и действует в пределах пользователя:
одинаковые параметры возвращают прежнюю посадку, другие параметры дают 409.
Это сохраняется после перезапуска. Оплата и реальная посадка не выполняются.

## Ограничения

Один процесс API на один JSON-файл, без конкурентной записи из разных процессов.
Синхронные bcrypt/файловые операции подходят для небольшой учебной демонстрации.
Сессии не переживают перезапуск. localStorage и HTTP допустимы для этой локальной
лабораторной; нет production-защиты, восстановления паролей и rate limiting.
Карта зависит от внешнего CDN Leaflet и тайлов OpenStreetMap.
Установка npm сообщила 6 уязвимостей зависимостей (3 moderate, 3 high);
автоматическое обновление всего стека за пределами задания не выполнялось.
Реальная оплата, физическая посадка и публикация API в интернет не реализуются.
