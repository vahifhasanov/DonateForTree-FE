# Пропозиція PR: lab6 → main

Назва: Лабораторна №6: бізнес-логіка посадки дерев, авторизація та інтерактивна карта

Статичні форми та колекції підключено до локального HTTP API зі збереженням JSON.
Додано власні хуки, демонстраційну реєстрацію/вхід, захищені маршрути, посадку з перевіркою,
підтвердженням та захистом від повторного POST. Статистика рахується за даними.
Замість зображення карти використано Leaflet/OpenStreetMap з пошуком, фільтрами та popup.
Збережено попередню композицію і компоненти. Додано README та матеріали звіту.

Перевірки: Vitest 46/46, production build; ESLint після виправлення конфігурації Cypress.
Обмеження: Cypress не стартує у поточній Windows-пісочниці; інтерактивність і адаптивність
потребують браузерного прогону. Leaflet завантажується з CDN, потрібен інтернет.
Авторизація локальна навчальна; платежів немає. Локальна база та токени не включаються в Git.

Commit, push, створення PR і merge очікують окремого рішення користувача.
